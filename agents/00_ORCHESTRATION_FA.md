# هماهنگی ایجنت‌ها — مرحله نرم‌افزار، ابزارها و گرافیک

هر ایجنت دستور **مستقل** دارد، خروجی خودش را در پوشه خودش می‌گذارد، و
شکست یکی بقیه را متوقف نمی‌کند. این فایل نقشه است.

| ایجنت | دامنه | خروجی | وابسته به |
|---|---|---|---|
| **A — داده** | ۱۹ KPI روی اسکیمای واقعی | `agents/A_dashboard_queries.py` + تست | — |
| **B — طراحی** | توکن‌ها، رنگ، تایپوگرافی، RTL | `src/.../Design/Theme.v2.xaml` | — |
| **C — پورت C#** | `IDashboardStore` + پیاده SQLite | `src/.../Dashboard/*.cs` | A |
| **D — UI داشبورد** | MainWindow، کارت‌ها، نمودارها | `src/.../MainWindow.xaml` | B, C |
| **E — ابزارها** | مرکز واردسازی، پشتیبان، گزارش | `src/.../Tools/*.xaml` | B |
| **F — نمایشگر دوم** | پنجره مستقل تمام‌صفحه | `SecondMonitorWindow.xaml` | C |

## قاعده‌ای که همه رعایت می‌کنند

- هیچ مقدار mock در UI نمی‌رود. حالت خالی صریح نمایش داده می‌شود.
- هر KPI باید **دو عدد** بدهد: تأییدشده و بررسی‌نشده (فصل ۱۱ مشخصات).
- رنگ برند `#075E1E` و رنگ‌های عملیاتی بانکی از فصل ۱۲.
- C# نوشته‌شده ≠ تست‌شده. تا build روی ویندوز، برچسب `NOT RUN` می‌ماند.
