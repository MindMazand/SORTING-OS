# ایجنت B — طراحی، گرافیک و RTL

**دستور:** هویت بصری سطح «نرم‌افزار تجاری ممتاز» بساز (فصل ۱۲ مشخصات)، روی
WPF و .NET Framework 4.8. بدون وابستگی خارجی، بدون فونت دانلودی.

## آنچه فصل ۱۲ صریح می‌خواهد

| مورد | الزام |
|---|---|
| راست‌چین واقعی | `FlowDirection=RightToLeft` در ریشه، نه فقط در چند کنترل |
| فونت فارسی حرفه‌ای | باید روی Windows 8.1 x64 **موجود** باشد |
| Glassmorphism کنترل‌شده | نیمه‌شفاف، نه محو؛ خوانایی مقدم بر زیبایی |
| دکمه‌های شیشه‌ای | با حالت hover/pressed/disabled |
| نمودار تحلیلی | بدون کتابخانه خارجی |
| انیمیشن کوتاه و هدفمند | نه چرخان، نه چشمک‌زن |
| رنگ برند | `#075E1E` |

## تصمیم‌های فنی که در همین ایجنت گرفته شد

1. **فونت:** `Segoe UI` روی همه نسخه‌های ویندوز ۸.۱ هست و فارسی را می‌کشد.
   `Vazirmatn` زیباتر است ولی نصب‌نشده بودنش یعنی متن پیش‌فرض نامناسب.
   زنجیره: `Segoe UI, Tahoma, Arial`. اگر مالک فونت بهتری نصب کرد، از تنظیمات
   عوض می‌شود — `PersianFont` یک `FontFamily` قابل بازنویسی است.

2. **نمودار:** هیچ `LiveCharts`/`OxyPlot`. هر KPI گرافیکی با
   `Path`/`Polyline` رسم می‌شود. دلیل: بسته باید آفلاین روی Win 8.1 نصب شود و
   وابستگی NuGet یعنی ریسک نصب.

3. **رنگ‌ها:** از spec، با سه افزوده که spec ذکر نکرده ولی بدونشان UI
   ناقص است — `DangerBrush` (منفی/مغایرت)، `WarningBrush` (نزدیک سررسید)،
   `PendingBrush` (بررسی‌نشده). هر سه از رنگ‌های عملیاتی موجود مشتق شدند.

4. **حرکت:** فقط ۳ انیمیشن، هر کدام زیر ۲۰۰ms: ورود کارت، تغییر عدد KPI،
   باز شدن منوی `+`. بیشتر از این، سرعت کار روزمره را می‌گیرد.

## تحویل

`src/Mazandasht.Presentation/Design/Theme.v2.xaml` — یک `ResourceDictionary`
که هر رنگ، فونت، سایه، دکمه، کارت، جدول و نشان وضعیت را تعریف می‌کند و
`Theme.xaml` قدیمی را جایگزین می‌کند.

**قاعده:** هیچ رنگ hex ای نباید مستقیم در XAML صفحه‌ها بیاید. اگر رنگی لازم
شد، اول توکنش اینجا ساخته می‌شود. رنگ پراکنده یعنی تم قابل تغییر نیست.
