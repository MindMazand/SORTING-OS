# تلاش برای کامپایل C# در این محیط — ۲۰۲۶-۱۱-۱۷

هدف: تبدیل «نوشته‌شده و از نظر نحوی بررسی‌شده» به «کامپایل‌شده». نتیجه:
**نشد.** این گزارش تلاش‌های واقعی و دلیل نهایی را ثبت می‌کند تا کسی دوباره
همان مسیر را نرود.

## چه چیزهایی امتحان شد

| مسیر | نتیجه |
|---|---|
| `apt-get install mono-mcs` | «Unable to locate package» — مخزن دبیان در دسترس نیست |
| `apt-get update` با `sudo` | `deb.debian.org` مسدود است (connection failed) |
| npm: بستهٔ `dotnet-sdk` | نصب‌کنندهٔ ماکت است؛ در زمان اجرا از `registry.yarnpkg.com` دانلود می‌کند که مسدود است |
| تاربال مستقیم از `registry.npmjs.org` | **شد** — `.NET Core 2.0 runtime` دانلود و اجرا شد (`dotnet --info` جواب داد) |
| تاربال `dotnet-sdk-2.0.0-linux` (۱۳۴MB) | استخراج شد، ولی اجرا شکست: `libunwind.so.8: cannot open shared object file` |
| ساخت libunwind از سورس (github/codeload باز بود) | فایل tar دانلود شد، ولی تگ v1.6.2 نه `configure` دارد نه `autoconf` در محیط هست؛ CMake هم در آن تگ **فقط Visual Studio** را پشتیبانی می‌کند |
| نصب `cmake` از PyPI | شد (wheel آماده) — ولی مشکل بالا با cmake حل نشد چون CMakeLists فقط MSVC را می‌پذیرد |
| استخراج `libunwind` از باینری استاتیک PyPI (`py-spy`) | باینری استاتیک است و کتابخانهٔ جدا بیرون نمی‌دهد |

بنابراین **هیچ کامپایلر C# در این محیط قابل نصب نیست.**

## نکتهٔ مهم‌تر: کامپایل هم مسئله را حل نمی‌کرد

حتی اگر `dotnet build` کار می‌کرد، هدف پروژه **.NET Framework 4.8 روی
Windows 8.1 x64 با WPF** است:

- WPF فقط روی ویندوز اجرا می‌شود؛ روی لینوکس نه build می‌شود نه اجرا.
- `System.Data.SQLite` و لایهٔ نمایش به ویندوز گره خورده‌اند.
- `dotnet test` روی xUnit هم به همان زنجیره نیاز دارد.

پس کد C# **باید** روی یک ماشین ویندوزی ساخته شود. این گزارش جایگزین آن نیست.

## چه چیزی این شکاف را کوچک می‌کند

سه نگهبان که **بدون** .NET اجرا می‌شوند و اگر کد C# از مرجع فاصله بگیرد
می‌شکنند:

1. `check_contract_parity.py` — ۱۲۹ فیلد و ۱۸ جدول، ستون‌به‌ستون
2. `check_csharp_schema.py` — هر ستونی که C# لمس می‌کند + طرح برگشت هر ۱۱ قالب
3. `check_contract_schema.py` — نگاشت `db_column` قرارداد با اسکیما

پس احتمال «کد C# ساخته شود و رفتار متفاوتی داشته باشد» پایین است، ولی
**صفر نیست**، و تا build نشود نمی‌توان گفت صفر است.
