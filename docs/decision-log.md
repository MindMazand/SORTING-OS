# دفتر تصمیمات — SORTING OS / مازندشت

## DEC-NEW-001 — جایگزینی سند مرجع (2026-11-17، Accepted)

سند «دستور جامع طراحی، توسعه و ساخت نرم‌افزار مازندشت» نسخه ۱.۰ (مالک محصول: مهندس مجید عیسی‌پور) به‌عنوان **سند مرجع حاکم** ثبت شد (`docs/MAZANDASHT_SPEC_FA.md`) و در موارد تعارض بر `PROJECT_SPEC.md` v1.1 مقدم است. `PROJECT_SPEC.md` برای تاریخچه حفظ می‌شود.

پیامدها:
- فناوری: WPF + C# + .NET Framework 4.8 + SQLite x64 (جایگزین Python/Tkinter).
- سیستم‌عامل هدف: Windows 8.1 x64 به بالا (جایگزین Windows 7 SP1).
- مدل کاربری: Single + تأیید مدیر.
- موجودی: Simple + Detailed از یک Stock Movement Ledger.
- پول: ریال صحیح در دیتابیس؛ تومان صرفاً واحد نمایش (Toman = Rial / 10).
- وزن: گرم صحیح؛ حداکثر ۳ رقم اعشار کیلوگرم در قالب‌های فعلی؛ گردکردن ۲ رقم اعشار در موتور اصلی ممنوع.
- دکمه عملیات سریع +، نمایشگر دوم، Import هوشمند Excel/CSV، Reset با عبارت `RESET MAZANDASHT`، Backup با SHA-256 و Manifest.

## DEC-NEW-002 — معماری لایه‌ای (2026-11-17، Accepted)

پنج لایه طبق فصل ۳ سند جدید: Presentation (WPF) / Application Services / Domain / Persistence / Infrastructure. مسیر `src/`:
- `Mazandasht.Domain` — قواعد خالص (پول، وزن، گردکردن، تراز دوبل، موازنه سورتینگ، تسویه، کدینگ، وضعیت تأیید).
- `Mazandasht.Application` — سرویس‌های کاربردی (باسکول، سورتینگ، فاکتور، تسویه، Backup، Reset، Import Registry).
- `Mazandasht.Persistence` — SQLite، Migration نسخه‌دار، Repositoryها.
- `Mazandasht.Infrastructure` — PBKDF2-HMAC-SHA256، کلید خصوصی ۳۲ بایتی، Audit، اتصال SQLite.
- `Mazandasht.Presentation` — WPF، RTL، داشبورد، نمایشگر دوم.
- `Mazandasht.Tests` — xUnit (اجرا روی Windows).

## DEC-NEW-003 — محیط ساخت و راستی‌آزمایی (2026-11-17، Accepted)

sandbox توسعه فاقد .NET است؛ بنابراین:
- کد C# به‌عنوان سورس تحویلی نوشته می‌شود و وضعیت آن `IMPLEMENTED (NOT RUN)` است تا روی Windows 8.1+ ساخته و تست شود.
- لایه دیتابیس (اسکیما + سید + قیود + ویوها) با `tools/verify_database.py` روی SQLite واقعی ساخته و تست می‌شود؛ نتایج در `reports/BASELINE.md` ثبت می‌گردد.
- هیچ ادعای «تست‌شده» برای C# بدون اجرای واقعی روی Windows پذیرفته نیست.
