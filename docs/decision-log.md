## DEC-NEW-001 — جایگزینی سند مرجع (2026-11-17، Accepted)

سند «دستور جامع طراحی، توسعه و ساخت نرم‌افزار مازندشت» نسخه ۱.۰ (مالک محصول: مهندس مجید عیسی‌پور) به‌عنوان **سند مرجع حاکم** ثبت شد (`docs/MAZANDASHT_SPEC_FA.md`) و در موارد تعارض بر `PROJECT_SPEC.md` v1.1 مقدم است. `PROJECT_SPEC.md` برای تاریخچه حفظ می‌شود.

پیامدها:

- سیستم‌عامل هدف: Windows 8.1 x64 به بالا (جایگزین Windows 7 SP1).

- دکمه عملیات سریع +، نمایشگر دوم، Import هوشمند Excel/CSV، Reset با عبارت `RESET MAZANDASHT`، Backup با SHA-256 و Manifest.

- DEC-NEW-013 — **قرارداد اجرای مهاجرت** (2026-11-17، Accepted): `MigrationRunner` بازنویسی شد چون نسخه قبلی سه نقص واقعی داشت:
  1. `PRAGMA foreign_keys=OFF` را **داخل** تراکنش صادر می‌کرد؛ SQLite آن را بی‌صدا نادیده می‌گیرد، در نتیجه بازسازی جدول با FK فعال انجام می‌شد.
